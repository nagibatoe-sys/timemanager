# Смена — веб-прототип

Откройте `index.html` в браузере. Для работы геолокации лучше запускать через HTTPS или локальный сервер; при открытии напрямую браузер может заблокировать разрешение на геолокацию.

## Демо-доступы

- Администратор: `admin` / `admin123`
- Руководитель: `manager` / `manager123`
- Сотрудник 1: `employee1` / `worker123`
- Сотрудник 2: `employee2` / `worker123`

## Что уже работает

- авторизация с разными ролями;
- кабинет сотрудника с началом и завершением смены;
- запрос геолокации через браузерный Geolocation API;
- сохранение отметок и координат в `localStorage` браузера;
- офлайн-режим: начало/конец смены и геопозиция попадают в локальную очередь и автоматически синхронизируются при событии `online`;
- обзор руководителя с картой, статусами и журналом смен;
- раздел сотрудников;
- админ-панель для создания пользователей с ролями «сотрудник», «руководитель» и «администратор»;
- выгрузка журнала в CSV.

Это демонстрационная версия без серверной базы данных: для реальной эксплуатации следующим шагом нужны backend, безопасное хранение паролей, серверная авторизация, база данных, права доступа и полноценная карта (например, Яндекс Карты или OpenStreetMap).
