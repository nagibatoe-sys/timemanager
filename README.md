# Смена

Веб-приложение для учета рабочих смен и геолокации сотрудников.

## Возможности

- авторизация по ролям: администратор, руководитель, сотрудник;
- открытие и закрытие смены с отправкой геопозиции;
- офлайн-очередь отметок с синхронизацией после восстановления сети;
- карта и журнал смен для руководителя;
- экспорт журнала в CSV;
- создание пользователей в админ-панели.

## GitHub Pages

Публикация настроена через `.github/workflows/pages.yml`. После завершения workflow приложение будет доступно по адресу:

https://nagibatoe-sys.github.io/timemanager/

Демо-доступы находятся в интерфейсе входа. Это прототип: для промышленной эксплуатации нужны backend, база данных и безопасное хранение паролей.
